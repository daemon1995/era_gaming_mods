Difficulty Mod - Help
=====================

Readme.txt in the mod root: overview, requirements and general use.
Changelog.txt in the mod root: release history, separate from the overview.
Options/: one short text per option or closely related setting.
Options/*.txt: current option documentation.
Backups/: original documentation before this reorganization; not needed to play.

Option descriptions explain the gameplay purpose, not a dated development history.
For new options, add a short text with What it does, How to use it and Purpose.
