Growth Limit
============

What it does
Raises the maximum size of growing neutral stacks; it does not increase growth speed. Disabled: normal 4,000 cap.

How to use it
Enable the option and select stage 1-4 with the arrows. Limits for creature levels 1 to 7:
Stage 1: 20,000 / 15,000 / 12,500 / 10,000 / 8,000 / 6,000 / 5,000
Stage 2: 40,000 / 30,000 / 25,000 / 20,000 / 16,000 / 12,000 / 10,000
Stage 3: 60,000 / 45,000 / 37,500 / 30,000 / 24,000 / 18,000 / 15,000
Stage 4: 80,000 / 60,000 / 50,000 / 40,000 / 32,000 / 24,000 / 20,000
Stage 2 retains the former limits.

Purpose
Allow neutral armies to remain a challenge on long maps without forcing one extreme cap on every creature level.
