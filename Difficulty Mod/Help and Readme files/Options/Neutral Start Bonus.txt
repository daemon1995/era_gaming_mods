Neutral Start Bonus
===================

What it does
Each level adds +1 Attack, +1 Defense and +5% HP in battle. Level 0 gives no bonus; level 10 gives +10/+10/+50%. The bonus applies from the first battle.

How to use it
Choose a strength with the arrows. The checkbox applies the same bonus to AI armies. This option adds no speed.

Purpose
Offer an immediate challenge without waiting for time-based scaling.
