Neutral Stack Size
==================

What it does
Adds a fixed number of creatures to map stacks according to creature level and the selected difficulty. Insane II adds 50% more than Insane. None disables these additions.

How to use it
The adjacent checkbox also enables extra AI starting and initial recruitable town troops. It does not switch the neutral bonus itself on or off. Existing no-growth and always-join exclusions apply.

Purpose
Make map guards stronger from the beginning; optional AI compensation helps computer players cope with those guards.
