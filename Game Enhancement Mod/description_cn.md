**优化增强Mod**（GEM）
作者：daemon_n

本Mod包含了大量基于脚本、插件和图像的改动：

视觉效果改动：
- 每个英雄职业在冒险地图和战斗中拥有独特的外观；
- 每个城镇等级在冒险地图上拥有独特的外观；
- 战斗中显示单位生命条（可选）；
- 扩展生物信息对话框；
- 扩展战斗中的部队信息预览对话框；
- 显示大额资源数值；
- 在所有城镇预览中显示城镇建筑状态；
- 当屏幕宽度足够时显示秘银图标（860）；
- 缩小“下一个英雄”按钮的宽度；
- 添加“设置菜单”按钮，用于打开Mod设置菜单（快捷键“~”）；
- 在小地图附近添加用于显示和管理快速战斗设置的按钮面板（可选）；
- 查看神器说明提示时显示主属性加成（可选）；
- 查看神器说明提示时显示组合神器部件（可选）；
- 在城镇窗口中添加打开额外设置菜单的按钮。

游戏玩法改动：
- 在城镇窗口中解雇英雄；
- 法术研究（可选）；
- 按下ALT键时，在冒险地图物体上方直接显示名称提示（可选）。

游戏交互快捷键：
- F1：打开帮助菜单；
- ALT（冒险地图）：在物体上方显示提示；
- ALT（冒险地图）：在状态栏显示路径长度；
- ALT+右击（冒险地图）：在独立消息中显示提示；
- ~（冒险地图）：打开Mod选项菜单；
- ~（城镇窗口）：打开额外城镇按钮菜单。

其他带来改动的插件和补丁：
- accumulate_8lv_creatures.bin - 8级生物可以在野外巢穴累积；
- accumulate_santagremlins_creatures.bin - 圣诞妖精可以在野外巢穴累积；
- ArtGuard.dll - 禁止分兵偷宝，进入野怪的一定范围内会强制触发战斗；
- BattleAIvsAIFix.dll - 让AI获得正确数量的经验值和招魂生物；
- BattleReplay.dll - 不满意战斗结果可以重新战斗！太棒了！
- BattleSave.dll - 战前自动存档，存档名为“BATTLE!”；
- draw soils.bin - 修正地形、道路和地形特定物体的显示；
- fast upgrade stacks in town.dll - 在城镇中按“A”+左键可快速升级生物；
- H3.RMGDescription.dll - 修正随机地图信息中的城镇表述，并且让随机地图信息可以翻译；
- StartArmyAllSlots.bin - 所有英雄起始生物为三队。
